# STP 26 — Desktop (1440) Implementation Plan

**Goal:** Add a responsive desktop layout (reference 1440px) on top of the existing, validated mobile UI, without breaking mobile.

**Architecture:** Mobile-first + Tailwind breakpoint overrides. Desktop layout flips at `xl` (1280px, Tailwind default). Content is constrained to the Desktop-xl grid: **max-width 1440, margin 80, gutter 32, 12 columns**. Full-bleed section backgrounds stay; content is centered in a shared `Container`.

## Global Constraints
- **Mobile must stay pixel-identical** below `xl`. All desktop changes are `xl:` overrides; `max-w-[1440px] mx-auto` is a no-op under 1440.
- Desktop-xl grid tokens (from `Breakpoints.tokens.json` → "Desktop xl"): margin **80**, gutter **32**, columns **12**, canvas **1440**. → content width = 1440 − 160 = **1280**.
- Column width @1280 content = (1280 − 11×32)/12 = **77.33px**; N-col span = N×77.33 + (N−1)×32.
- Breakpoint: `xl:` (1280px). Below → mobile.
- Values from tokens; no new hardcodes.

## Per-section desktop spec (from user)
- **Header** → xl variant: logo left · inline nav (5, gap 40) · small CTA right; hamburger hidden ≥xl.
- **Ticket cards** → 3 **inline, fill** content width (each `flex-1`, gap 32).
- **CardExpressive** → 2 **inline, centered** (natural 358px width, not fill), gap 32.
- **Location** → map left = **3 columns** (~296px), text+CTA right (rest).
- **Merch** → Banner **xl** variant (image+content horizontal).
- **Artists** → BannerSlim **xl** variant (content+CTA horizontal, full width).
- **Collaborate** → 2 BannerSlim stay **size s**, placed **inline** (2 cols, gap 32).
- Unspecified (Hero, Ticker, Creativity, Footer): sensible desktop = centered, constrained column; note as defaults.

## Files
- Modify: `src/styles/globals.css` (desktop grid tokens: `--desktop-margin`, `--desktop-gutter`)
- Create: `src/components/layout/Container.tsx` (max-w 1440 + responsive px)
- Modify: `Header.tsx`, `Banner.tsx`, `BannerSlim.tsx`
- Modify: all sections (`HeroSection`, `TicketSection`, `LocationSection`, `ArtistsSection`, `MerchSection`, `CollaborateSection`, `CreativitySection`, `FooterSection`)

## Task 1 — Foundation: tokens + Container
- Add to `@theme`: `--desktop-margin: 80px; --desktop-gutter: 32px;`
- Create `Container`: `mx-auto w-full max-w-[1440px] px-[var(--mobile-margin)] xl:px-[var(--desktop-margin)]` + `className` passthrough for layout classes.

## Task 2 — Banner & BannerSlim: make `size='desktop'` RESPONSIVE
Reinterpret `size='desktop'` = mobile layout as base + desktop layout at `xl:` (not unconditional). `size='mobile'` stays always-vertical.
- Banner desktop@xl: `xl:flex-row xl:gap-[var(--desktop-gutter)]`; media `xl:flex-1`; content `xl:flex-1 xl:justify-center xl:self-stretch`.
- BannerSlim desktop@xl: `xl:flex-row xl:items-center xl:gap-[var(--spacing-40)]`; content `xl:flex-1`; CTA `xl:shrink-0`.

## Task 3 — Header xl
- Restructure with inner `Container`-like wrapper; `justify-between`.
- Left cluster: hamburger (`xl:hidden`) + logo. Nav `hidden xl:flex gap-[40px]`. CTA small.
- `py-[var(--spacing-16)]`; horizontal via wrapper (`px-16 xl:px-80`).

## Task 4 — Sections: wrap in Container + desktop layout
Each section: keep full-bleed bg + vertical padding on `<section>`; move content into `<Container className="…layout… xl:…">`.
- **Hero**: content centered column `xl:max-w-[640px] xl:mx-auto` (avoid full-width CTAs); keep stacked.
- **Ticket**: card list `flex flex-col gap-24 xl:flex-row xl:gap-[var(--desktop-gutter)]`; each card `xl:flex-1`.
- **Location**: `xl:grid xl:grid-cols-12 xl:gap-[var(--desktop-gutter)]`; map `xl:col-span-3`; text+CTA `xl:col-span-9` (flex-col, justify-center).
- **Artists**: header centered; CardExpressive row `flex flex-col gap-40 xl:flex-row xl:justify-center xl:gap-[var(--desktop-gutter)]`, each card wrapper `xl:w-[358px]`; CTA `xl:w-auto`; BannerSlim `size='desktop'`.
- **Merch**: Banner ×2 `size='desktop'`.
- **Collaborate**: header; banners row `flex flex-col gap-24 xl:flex-row xl:gap-[var(--desktop-gutter)]`, each BannerSlim keeps `size='mobile'` (s), `xl:flex-1`.
- **Creativity/Footer**: content centered, constrained (`xl:max-w-…`).
